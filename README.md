# CV Pro — منصة سيرة ذاتية مدفوعة (عربي / إنجليزي)

المستخدم يكتب بياناته ويشاهد سيرته مباشرة مع تقييم حسب معايير التوظيف، ثم يدفع، ثم يحمّل PDF أو Word.
**الملف النهائي لا يُنشأ إلا على السيرفر وبعد وصول تأكيد دفع موقّع من بوابة الدفع.**

## ما في المشروع

| المسار | الوظيفة |
|---|---|
| `index.html` | صفحة الهبوط والأسعار |
| `builder.html` + `assets/builder.js` | منشئ السيرة: 8 خطوات، معاينة بعلامة مائية، تقييم ATS، الدفع والتحميل، المساعد الذكي |
| `account.html` + `assets/account.js` | سير المستخدم ومدفوعاته + لوحة الإدارة (موافقة CliQ، الإيراد، الأسعار) |
| `shared/templates.js` | 4 قوالب (كلاسيكي، عصري، ATS، طبي) — نفس الكود للمعاينة وللـ PDF النهائي |
| `shared/ats.js` | مقيّم HR: 13 معياراً ونصائح عملية |
| `api/checkout.js` | ينشئ صفحة دفع Lemon Squeezy مربوطة بالمستخدم والسيرة |
| `api/webhook.js` | **المكان الوحيد** الذي يفعّل الدفع بالبطاقة (توقيع HMAC + تطابق الباقة + منع التكرار) |
| `api/generate.js` | يتحقق من الطلب المدفوع ثم ينشئ PDF (Chromium) أو Word ويعطي رابطاً صالحاً 24 ساعة |
| `api/ai.js` | مساعد الصياغة لباقة «مميّز» (اختياري) |
| `supabase/schema.sql` | الجداول + صلاحيات RLS + دوال الإدارة + مخزن الملفات الخاص |
| `tests/` | 16 اختباراً: توقيع مزوّر، باقة لا تشمل Word، تغيير الاسم، حقن HTML… |

## كيف نضمن أن المستخدم دفع

1. المعاينة HTML عليها علامة مائية متكررة، والطباعة منها معطّلة. لا يوجد في المتصفح أي ملف نهائي.
2. جدول `orders` لا يستطيع المستخدم الكتابة فيه إطلاقاً (RLS). يكتب فيه السيرفر فقط.
3. الـ webhook يرفض أي طلب توقيعه غير مطابق لـ `LEMONSQUEEZY_WEBHOOK_SECRET`، ويتأكد أن الحالة `paid` وأن رقم الـ Variant يطابق الباقة.
4. `api/generate` يقرأ الطلب من قاعدة البيانات، لا من المتصفح، ويحفظ الملف في مخزن خاص ويعطي رابطاً مؤقتاً.
5. الاسم يُقفل عند أول تحميل: لا يمكن استخدام دفعة واحدة لعمل سير لعدة أشخاص.
6. حوالات CliQ لا تُفعَّل إلا بموافقة الأدمن بعد مطابقة الحوالة في تطبيق البنك.

## التشغيل خطوة بخطوة (حوالي ساعة)

### 1) Supabase
1. أنشئ مشروعاً جديداً، ثم SQL Editor والصق `supabase/schema.sql` واضغط Run.
2. Authentication → Providers: فعّل Email (و Google إن أردت).
3. Authentication → URL Configuration: ضع رابط موقعك في Site URL و Redirect URLs (مثل `https://cvpro.vercel.app/**`).
4. من Project Settings → API انسخ: Project URL و `anon` key و `service_role` key.

### 2) Lemon Squeezy (الدفع بالبطاقة)
1. أنشئ متجراً وفعّل وسيلة استلام الأرباح المتاحة لحسابك (تحقق من الدول المدعومة وقت التسجيل).
2. أنشئ منتجاً واحداً «CV Pro» بثلاثة Variants: Basic ‏$5، Pro ‏$9، Premium ‏$19.
3. انسخ رقم كل Variant وضعه في لوحة الإدارة بالموقع (أو SQL):
   `update packages set ls_variant_id = '123456' where code = 'pro';`
4. Settings → API: أنشئ API key.
5. Settings → Webhooks: الرابط `https://موقعك/api/webhook`، الأحداث `order_created` و `order_refunded`، واكتب Signing secret طويلاً عشوائياً.

### 3) النشر على Vercel
1. ارفع المجلد إلى GitHub (مثلاً `mam87/cv-pro`) واستورده في Vercel.
2. Settings → Environment Variables: انسخ القيم من `.env.example` واملأها.
3. عدّل `assets/config.js`: ضع `SUPABASE_URL` و `SUPABASE_ANON_KEY` واسم CliQ المستعار. (المفتاح anon آمن للنشر؛ مفتاح service_role لا يوضع هنا أبداً.)
4. Deploy.

> لماذا Vercel وليس GitHub Pages؟ GitHub Pages لا يشغّل كود سيرفر، وتوليد PDF عربي بجودة طباعة يحتاج متصفح Chromium على السيرفر. Vercel يستضيف الواجهة والـ API معاً مجاناً في البداية.

### 4) اجعل نفسك أدمن
بعد أول تسجيل دخول، في SQL Editor:
```sql
update public.profiles set role = 'admin'
where id = (select id from auth.users where email = 'بريدك@example.com');
```

### 5) جرّب قبل الإطلاق
1. فعّل Test mode في Lemon Squeezy، وضع مؤقتاً `ALLOW_TEST_PAYMENTS=1` في Vercel.
2. ادفع ببطاقة الاختبار `4242 4242 4242 4242`. يجب أن يظهر زر التحميل خلال ثوانٍ.
3. **اختبارات إلزامية:**
   - افتح `builder.html` بحساب آخر لم يدفع: زر التحميل غير موجود، واستدعاء `/api/generate` يرجع 402.
   - أرسل طلباً مزوّراً إلى `/api/webhook` بدون توقيع: يرجع 401.
   - غيّر الاسم في سيرة مدفوعة: يرفض التحميل برسالة واضحة.
   - باقة Basic لا تعطي Word.
4. احذف `ALLOW_TEST_PAYMENTS` وأوقف Test mode.

اختبارات الكود: `npm install && npm test`

## التسعير والدخل

| الباقة | CliQ | بطاقة | لمن |
|---|---|---|---|
| أساسي | 3 د.أ | $5 | حديثو التخرج |
| احترافي | 6 د.أ | $9 | **الهدف الرئيسي** — PDF + Word + 30 يوم تعديل |
| مميّز | 12 د.أ | $19 | المتقدمون للخليج والوظائف الإشرافية — مساعد ذكي + رسالة تغطية |

الأسعار قابلة للتعديل من لوحة الإدارة بدون تعديل كود. أفكار لزيادة الدخل:
- اربط الموقع بمنصة «فرصة»: زر «جهّز سيرتك» بجانب كل وظيفة.
- عروض للجامعات ومراكز التدريب (أكواد خصم جماعية من Lemon Squeezy).
- خدمة «مراجعة بشرية» بـ 15 د.أ تقدّمها أنت أو متعاون HR.

## الخصوصية
- لا تُخزَّن أي بيانات بطاقة لدينا؛ الدفع كاملاً عند Lemon Squeezy.
- البيانات محمية بـ RLS: كل مستخدم يرى سيره فقط.
- أضف صفحة سياسة خصوصية وسياسة استرجاع قبل الإطلاق (Lemon Squeezy يطلبهما).
